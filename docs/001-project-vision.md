# ADR-001: Project Vision

Date: 2026-06-06

## Status

Accepted

## Context

Users currently rely on app stores to find software solutions for their needs.

Many users require simple custom applications that do not exist or are too specialized to justify dedicated development.

Examples:

* Study planners
* Habit trackers
* Custom calculators
* Flashcard systems
* Personal dashboards
* Simple games

Traditional software discovery requires:

1. Searching
2. Installing
3. Configuring
4. Evaluating

This process is inefficient when users only need a small personalized tool.

## Decision

Build AnyApp.

AnyApp allows users to describe a software solution using natural language and instantly receive a working application.

Tagline:

Describe it. Use it.

Future Tagline:

Describe it. Use it. Share it.

## Scope

Supported:

* Calculators
* Productivity tools
* Educational tools
* Habit trackers
* Notes
* Simple games
* Dashboards

Not Supported:

* Messaging applications
* Banking applications
* Crypto wallets
* Social networks
* Applications requiring advanced device permissions

## Consequences

Benefits:

* Clear MVP scope
* Reduced security risks
* Faster development
* Easier validation of product-market fit

Tradeoffs:

* Users may request unsupported applications
* Product capabilities intentionally limited during early stages
